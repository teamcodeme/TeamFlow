# TeamFlow API

The main backend REST API service for TeamFlow, generated by GO-DUCK.

## Structure

- `cmd/` - Command-line entry points (if any)
- `internal/`
  - `domain/` - Domain entities and business logic (generated by go-duck)
  - `application/` - Use cases and application services (generated by go-duck)
  - `infrastructure/` - Database, external services, HTTP handlers (generated by go-duck)
  - `ports/` - Interface definitions for external adapters
- `pkg/` - Reusable packages
- `migrations/` - Database migration scripts

## Generation

This codebase is primarily generated using GO-DUCK. Do not manually edit files marked with GO-DUCK needle comments.

To regenerate:
```bash
cd ../../
go-duck generate
```

## Running

```bash
cd ../../
go run ./apps/api
```

## Testing

```bash
cd ../../
go test ./apps/api/...
```
